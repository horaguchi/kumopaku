# Kumopaku

Kumopaku is a 2D roguelike game developed for the [7DRL Challenge 2026](https://itch.io/jam/7drl-challenge-2026).

## Features

- Procedurally generated dungeons
- Turn-based combat
- Skill system
- Localization support
